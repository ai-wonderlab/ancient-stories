# research/

_Ό,τι χρειαστεί για συγκεκριμένη ιστορία._

---

## Τι μπαίνει εδώ

- Πρωτότυπα κείμενα (π.χ. Γκιλγκαμές σε αγγλική μετάφραση του Andrew George)
- Ελεύθερες αποδόσεις (π.χ. ο Παρμενίδης του Βούλγαρη)
- Εικαστικές αναφορές (references για visual direction)
- Τεχνικές σημειώσεις (AI models, pipelines)
- Pdfs, αποσπάσματα, notes

---

## Τι ΔΕΝ μπαίνει εδώ

- Κείμενα του Νίκου που έχουν τον τόνο του project → `voice/`
- Outputs ή drafts έργων → `works/<slug>/drafts/`
- Bearings → `bearings/`

---

## Οργάνωση

Ελεύθερη ανά έργο:

```
research/
  gilgamesh/
    george-translation.pdf
    etcsl-notes.md
    visual-refs/
  orphic/
    orphic-hymns-athanassakis.pdf
    ...
```

Κάθε subfolder μπορεί να έχει δικό του `README.md` αν χρειάζεται.

---

## Υπενθύμιση

**Η έρευνα είναι σκαλωσιά, δεν είναι περιεχόμενο.** Το έργο κρίνεται από την εμπειρία του θεατή, όχι από την ακαδημαϊκή ευσυνειδησία. Η έρευνα εδώ μας βοηθάει να νιώσουμε τη ρίζα — δεν μας αναγκάζει να τη στολίσουμε.
