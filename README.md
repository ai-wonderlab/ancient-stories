6. **[works/](works/)** — ένας φάκελος ανά έργο. Όταν ξεκινήσει το πρώτο πείραμα, γεννιέται εδώ.

7. **[research/](research/)** — ό,τι χρειαστεί για συγκεκριμένη ιστορία (πρωτότυπα κείμενα, μεταφράσεις, εικαστικές αναφορές).
