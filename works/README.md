# works/

_Ένας φάκελος ανά έργο._

---

## Δομή ενός έργου

Κάθε έργο έχει δικό του φάκελο με slug:

```
works/
  aris/                 (ο Άρης — έτοιμο αρχετυπικό, πρώτο prototype)
  gilgamesh/            (όταν/αν ξεκινήσει)
  adam-eve/             (όταν/αν ξεκινήσει)
  ...
```

Μέσα σε κάθε έργο (ελαστικό, όχι αυστηρό):

```
works/<slug>/
  README.md             — τι είναι το έργο, σε ποια φάση, φίλτρο ναι/ναι/ναι
  SCRIPT.md             — το σενάριο/αφήγηση
  SHOT-LIST.md          — σκηνές, planning
  VOICE-NOTES.md        — υπογραφή αφήγησης
  references/           — εικαστικές αναφορές, pdfs
  drafts/               — δοκιμαστικά outputs (video, audio, image)
  final/                — το τελικό έργο
```

Δεν χρειάζεται να έχει όλα. Κάθε έργο παίρνει ό,τι χρειάζεται.

## Κανόνας εισόδου

Πριν μπει έργο εδώ, περνά το φίλτρο:

> Δημιουργεί φαντασιακό κόσμο; **ΝΑΙ**
> Έχει έντονο ιστορικό αποτύπωμα; **ΟΧΙ**
> Χρειάζεται σωστές ιστορικές αναφορές; **ΟΧΙ**

Αν κάποια απάντηση δεν ταιριάζει — δεν είναι έργο για εδώ.

## Υποψήφια (από το COMMON-GROUND, Μέρος 5)

Δεν είναι λίστα για επιλογή — πεδίο για να δούμε τι καλεί.

**Αρχετυπικές νέες:**
- Ο Άρης
- Ο Προφήτης που δεν ήθελε να μιλήσει
- Ο Νεκρομάντης που έμαθε να ακούει
- Η Γυναίκα που κουβαλούσε δέκα ονόματα
- Ο άνθρωπος που μπήκε στην ίδια ιστορία δύο φορές

**Καθαρά μυθικά κείμενα:**
Μεσοποταμιακά (Γκιλγκαμές, Enūma Eliš, Ινάννα, Adapa),
Αιγυπτιακά (Ani, Ίσιδα/Όσιρις),
Ελληνικά (Ορφέας, Ελευσίνια, Θεογονία, Σπήλαιο, Προμηθέας),
Ανατολικά (Mahabharata/Gita, Chuang Tzu, Tao Te Ching, Nachiketa),
Σκανδιναβικά/Άλλα (Ragnarök, Shahnameh, Popol Vuh, Anansi),
Εβραϊκά (Γένεση, Κοέλεθ, Ιώβ, Enoch),
Μυστικιστικά (Hermetica, Avesta, Μύθος του Μίθρα).
