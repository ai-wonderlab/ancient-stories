# Bearings

_Τακτικές επανευθυγραμμίσεις. Pattern από το Re-Member._

---

## Τι είναι ένα bearing

Όταν το COMMON-GROUND είναι γενικό και η τρέχουσα τριβή χρειάζεται ακριβή απόφαση, γράφεται bearing.

Ένα bearing απαντά σε:
- *Πού είμαστε τώρα;*
- *Τι αποφασίσαμε σήμερα που δεν υπήρχε στο common ground;*
- *Τι άλλαξε;*

Δεν αντικαθιστά το common ground — το ενημερώνει.

---

## Μορφή αρχείου

Όνομα: `YYYY-MM-DD.md` (π.χ. `2026-04-20.md`)

Δομή (ελαστική):

```markdown
# Bearing — YYYY-MM-DD

## Πού είμαστε
(μία-δύο προτάσεις για την τρέχουσα κατάσταση)

## Τι αποφασίσαμε σήμερα
(συγκεκριμένες αποφάσεις — όχι θεωρία)

## Τι άλλαξε
(αν άλλαξε κάτι στο common ground/north star, καταγράφεται εδώ)

## Επόμενο βήμα
(μία ενέργεια, όχι λίστα)
```

---

## Πότε γράφεται

- Όταν τελειώνει μια σημαντική συνομιλία
- Όταν πρέπει να σταθεροποιηθεί μια απόφαση πριν χαθεί
- Όταν ένα έργο ξεκινάει/αλλάζει/τελειώνει
- Όταν ο Νίκος λέει *«γράψε το»*

## Πότε ΔΕΝ γράφεται

- Για κάθε μικρή συζήτηση
- Για πράγματα που ανήκουν στο common ground
- Για checklist/todo (αυτό δεν είναι bearing)
